How it works

Actual MPH is calculated as 3,600 divided by the AS400 Total Time. When a slider moves, the app adds only that metric’s change to the original Total Time, so hidden time such as Non-Sales Time remains included. Warehouse comparisons use the same performance date as the cashier’s latest record.
